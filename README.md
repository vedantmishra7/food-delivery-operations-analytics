Project Overview

This project analyses food delivery operations using Microsoft Power BI. It presents an interactive dashboard designed to explore order volume, delivery duration, delivery distance, traffic density, weather conditions, vehicle types, and city-level patterns.

Objectives

- Examine delivery-time patterns across traffic and weather categories.
- Compare delivery performance across cities and vehicle types.
- Explore the relationship between delivery distance and delivery duration.
- Provide interactive filters to support exploratory analysis.

Tools and Technologies

- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and KPIs
- GitHub for project documentation and version control

Dataset

The project uses the Zomato delivery dataset, "zomato_cleaned.csv".

Source: https://huggingface.co/datasets/allenborochin/zomato_delivery_EDA

The dataset is used for educational and analytical purposes. Refer to the original source for its description and licensing information.

Dashboard Pages

1. Overview — KPI cards, delivery time by traffic and weather, and orders by city.
2. Operation Analysis — comparisons involving vehicle type, order type, multiple deliveries, and festival status.
3. Delivery Performance — delivery-time trends, rating-related analysis, distance by city, detailed records, and filters.

Key Measures

- Total Orders
- Average Delivery Time
- Average Distance

The measures and their definitions should be documented alongside the final dashboard.

Interpretation Note

Dashboard values and patterns should be interpreted in the context of the available dataset. Observed associations do not establish causation, and findings should be verified against the underlying data before being presented as conclusions.
